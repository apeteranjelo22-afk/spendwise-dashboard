
# SpendWise Interactive Budget Dashboard

## Project Description

SpendWise is an interactive personal budgeting application
developed using HTML, CSS and JavaScript.

It allows users to set a monthly budget, add expenses,
view expense records, calculate total spending and monitor
their remaining balance.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## Improvements Made This Week

This week, I upgraded SpendWise from a static dashboard
to an interactive budgeting application.

Users can now add, view and delete expense records,
update their monthly budget and see their financial
information displayed dynamically.

## JavaScript Concepts Implemented

### 1. Conditional Statements

I used if, else if and else statements to check whether
the user is within budget, has used the entire budget
or has exceeded the budget.

### 2. Arrays

I used an expenses array to store multiple expense
records. Each record contains an ID, description,
category and amount.

### 3. Loops

I used a for loop to calculate total expenses and a
forEach loop to display all expense records.

### 4. DOM Manipulation

I used document.getElementById(), createElement(),
appendChild() and textContent to update dashboard
information and display expense records directly
on the webpage.

### 5. Event Handling

I used addEventListener() to respond to form submissions
and button clicks.

The application allows users to update their budget,
add expenses and delete existing expense records.

### 6. Functions

I created reusable functions including:

- calculateTotalExpenses()
- calculateBalance()
- updateBudgetStatus()
- displayExpenses()
- updateDashboard()
- formatMoney()

These functions organize the application logic and
make the code easier to maintain.

## Challenges Encountered and Solutions

One challenge was displaying multiple expense records
on the webpage. I solved this by using arrays, loops
and DOM manipulation.

Another challenge was calculating the remaining budget
after adding or deleting expenses. I solved this by
creating reusable calculation functions.

I also used input validation to prevent invalid
financial information from being processed.

## Project Files
