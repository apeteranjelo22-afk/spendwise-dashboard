# SpendWise Dashboard Shell

## Project Description

SpendWise is a responsive personal finance dashboard
created using HTML and CSS.

The project demonstrates how CSS Grid and Flexbox
can be used to create a modern dashboard layout.

## Project Features

1. Sidebar navigation menu.
2. Dashboard header and profile section.
3. Financial summary cards.
4. Six expense category cards.
5. Responsive layout for mobile devices.
6. CSS hover and keyboard focus animations.
7. CSS custom properties for consistent styling.
8. Optional dark theme.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Variables
- Media Queries

## Project File Structure

- index.html: Contains the dashboard structure and content.
- style.css: Controls the colors, layout, responsiveness,
  animations and dark theme.
- README.md: Explains the project and its features.
